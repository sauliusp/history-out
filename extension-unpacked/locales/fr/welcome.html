Commencez sans compte ni configuration. L’historique est lu uniquement à votre demande.

Ouvrir HistoryOut →Ouvrir dans un onglet complet

Ouvrez-le à côté de cette page ou dans un onglet complet.

Ouvrez HistoryOut dans le menu des extensions. Épinglez son icône bleue à la barre pour la retrouver facilement.

  1. Regardez votre journée. Choisissez Aujourd’hui et Aperçu.
  2. Trouvez une page utile. Cherchez un mot du titre ou de l’URL, ou choisissez un site principal, puis ouvrez le lien.
  3. Gardez un fichier au besoin. CSV pour les tableurs, JSON pour les données, HTML pour une liste lisible.
