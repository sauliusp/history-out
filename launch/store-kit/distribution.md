# Browser distribution

Verified against official sources on 5 September 2026.

| Browser | How people install it | What is prepared |
| --- | --- | --- |
| Chrome desktop | Existing Chrome Web Store item | Tested release package, copy, five screenshots, two promos and original icon |
| Microsoft Edge desktop | Chrome Web Store, or a separate Edge Add-ons listing | Edge package and a separate submission kit |
| Brave desktop | Chrome Web Store | Same public install destination; a Brave build is also packaged for verification |
| Other Chromium browsers | Depends on that browser's extension support and distribution rules | Generic full-page package with reduced permissions; check each browser before claiming support |
| Firefox, Safari, mobile | Outside the current package's supported scope | No misleading store badges or unsupported download claims |

Brave documents installing compatible extensions directly from the Chrome Web Store. There is no separate Brave marketplace submission needed for this launch. This distribution path does not by itself certify every HistoryOut feature in Brave. [Brave installation instructions](https://support.brave.app/hc/en-us/articles/360017909112-How-can-I-add-extensions-to-Brave)

Edge supports Chrome Web Store installations and also has its own Add-ons store. Start with the existing Chrome item, then publish the prepared Edge listing after its final checks. [Microsoft installation instructions](https://support.microsoft.com/en-US/edge/add-turn-off-or-remove-extensions-in-microsoft-edge), [Microsoft Edge extension overview](https://learn.microsoft.com/en-us/microsoft-edge/extensions/)

Do not create another Chrome item for the update, do not invent a Brave store badge, and do not imply that every Chromium browser has been tested. Keep one recognizable HistoryOut identity across all channels.
